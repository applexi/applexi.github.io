This project is meant to implement assistive technology to allow people with visual impairments to "see" facial expressions of the people around them. A camera attached to an RPI takes in live stream of images, which is processed in a Flask server w/ AI algorithm that outputs a file storing the emotions vector. This is then processed by the visualization interface.

A Tartanhacks 2023 project by Aprille Xi, Gabriel Hall, and Spencer Li.

Awarded Best AI project and Top 5 Overall.
